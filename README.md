# EsencialesProyectos
Cosas que no me debo olvidar al hacer un proyecto.

**Alcance:** escritos desde un proyecto de software que corre en un server propio, con datos
sensibles, hecho por un equipo chico durante meses, con IA como asistente cotidiano. Las reglas
de seguridad sirven a cualquier repo; las de método, frontera e IA, a proyectos que duran y
donde hay otros que tienen que entender.

**Para una IA:** si te pasaron este repo, leé el índice, abrí el doc que aplica al repo donde
estás trabajando, y decí qué falta ahí. No des por hecho que algo se cumple sin verificarlo.

- [Seguridad](SeguridadExp.md) — repo y CI: secretos, CVEs, Dependabot, permisos, accesos
- [Método](Metodo.md) — organizar (tablero, decisiones, docs), medir (clase, radares), decidir
- [Frontera entre equipos](Frontera-entre-equipos.md) — cuando otro equipo termina tu sistema: log de lo que llega, correlación, contrato
- [Trabajar con IA](Trabajar-con-IA.md) — CLAUDE.md, hooks, qué opera la IA y qué no
