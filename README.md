# EsencialesProyectos
Cosas que no me debo olvidar al hacer un proyecto.

**Alcance:** pensado para proyectos de software que duran meses, con un equipo chico, un server
propio y la IA como asistente cotidiano. Las reglas de seguridad sirven a cualquier repo; las de
método, frontera e IA, a proyectos donde hay otros que tienen que entender.

**Para una IA:** si te pasaron este repo, leé el índice, abrí el doc que aplica al repo donde
estás trabajando, y decí qué falta ahí. No des por hecho que algo se cumple sin verificarlo.

- [Seguridad](SeguridadExp.md) — repo y CI: secretos, CVEs, Dependabot, permisos, accesos
- [Método](Metodo.md) — organizar (tablero, decisiones, docs), medir (clase, radares, guardas), decidir (error visible, alcance de un fix)
- [Frontera entre equipos](Frontera-entre-equipos.md) — cuando otro equipo termina tu sistema: log de lo que llega, correlación, contrato, denominador del otro lado
- [Operación del server](Operacion-server.md) — server propio y compartido: limpiar Docker sin prune, salud visible, RAM, candados internos
- [Trabajar con IA](Trabajar-con-IA.md) — CLAUDE.md, hooks, qué opera la IA y qué no, secretos en el chat
